# 🧩 Latihan C++ – Operator Relasional

## 🎯 Tujuan
Melatih pemahaman dalam menggunakan operator relasional (`==`, `!=`, `>`, `<`, `>=`, `<=`) untuk membandingkan dua atau lebih nilai.

---

## 🧠 Soal 1 – Bandingkan Dua Angka
Buat program yang meminta dua bilangan bulat dari pengguna, lalu tampilkan hasil perbandingannya:
- Apakah `a` lebih besar dari `b`
- Apakah `a` sama dengan `b`
- Apakah `a` lebih kecil dari `b`

**Contoh Output:**
```
Input a: 10
Input b: 8
a > b : 1
a == b : 0
a < b : 0
```

---

## 🧠 Soal 2 – Cek Nilai Sama atau Tidak
Buat program untuk mengecek apakah dua angka yang dimasukkan **memiliki nilai yang sama**.

**Contoh Output:**
```
Masukkan angka pertama: 12
Masukkan angka kedua: 12
Apakah sama? 1
```

---

## 🧠 Soal 3 – Bandingkan Umur
Buat program untuk membandingkan dua umur dan tampilkan apakah umur pertama lebih tua, sama, atau lebih muda dari umur kedua.

**Contoh Output:**
```
Umur A: 20
Umur B: 25
Apakah A lebih tua? 0
Apakah sama umur? 0
Apakah A lebih muda? 1
```

---

## 🧠 Soal 4 – Nilai Lulus
Buat program yang menampilkan **1 (true)** jika nilai yang dimasukkan ≥ 60, dan **0 (false)** jika kurang dari 60.

**Contoh Output:**
```
Masukkan nilai: 75
Apakah lulus? 1
```

---

## 🧠 Soal 5 – Cek Angka Positif atau Negatif
Buat program untuk menentukan apakah suatu bilangan **positif**, **negatif**, atau **nol** hanya menggunakan operator relasional.

**Contoh Output:**
```
Masukkan angka: -5
Positif? 0
Negatif? 1
Nol? 0
```
