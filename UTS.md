# 📘 Soal UTS C++ – Dasar (Input, Output, Variabel, Aritmatika)

## Soal 1. Konversi Suhu
Buat program untuk mengonversi suhu dari **Celcius** ke **Fahrenheit**.  
Gunakan rumus:
```
F = (C * 9/5) + 32
```

**Contoh Eksekusi Program:**
```
Input Celcius: 25
Output Fahrenheit: 77
```
---

## Soal 2. Menghitung Keliling Lingkaran
Buat program yang menerima input jari-jari lingkaran (r) lalu menghitung keliling lingkaran, Guanakan rumus:
```
Keliling = 2 * 3.14 * r
```
---

## Soal 3. Pertukaran Nilai Variabel
Buat program yang membaca dua bilangan lalu menukar nilainya.
Contoh:
```
Input a: 10  
Input b: 20  
Output setelah ditukar → a = 20, b = 10
```

---

## Soal 4. Diskon Belanja
Buat program yang menghitung total harga belanja setelah diskon 10%.  

**Contoh Eksekusi Program:**
```
Input total belanja: 200000
Output setelah diskon: 180000
```

---

## Soal 5. Menghitung Umur
Buat program yang meminta input tahun lahir dan tahun sekarang, lalu menghitung umur.  

**Contoh Eksekusi Program:**
```
Input tahun lahir: 2005
Input tahun sekarang: 2025
Output: Umur kamu 20 tahun
```
